# Задание: статьи по категориям сырья

Ты — технолог-косметолог с опытом разработки рецептур и преподавания.
Нужно написать **полноценную справочную статью** по одной категории косметического
сырья. Читатель — технолог и разработчик рецептур, который хочет понять, что это
за группа, как она работает и как её применять.

## Что сделать

1. Прочитай образец готовой статьи: `F:\cosmetic-compound-base\data\example-article.json`.
   Он задаёт структуру, глубину и стиль. В образце — статья про загустители.
2. Прочитай список категорий: `F:\cosmetic-compound-base\data\categories.json` —
   там русские и английские названия, id и цвет.
3. Посмотри, какие позиции реально есть в каталоге по твоей категории:
   `F:\cosmetic-compound-base\data\materials.json` (поле `category`).
   Выбери из них **3–6 показательных** и укажи их `id` в поле `examples`.
4. Напиши статью и запиши её в файл, путь указан ниже.

## Требования к содержанию

Статья должна быть **содержательной, а не общей**. Плохо: «ПАВ — это вещества,
которые снижают поверхностное натяжение». Хорошо: объяснить механизм (мицелло­-
образование, ККМ, гидрофильно-липофильный баланс), показать, как это влияет на
рецептуру, и дать конкретные цифры.

Обязательно раскрой:

* **что это за группа** и по какому признаку вещества в неё объединяют;
* **механизм действия** — физика и химия процесса, а не только определение;
* **подклассы внутри категории** с названиями конкретных веществ и их отличиями
  (у каждого подкласса — `name` и описание: в чём разница, когда выбирать);
* **как выбирать** — на что смотреть в спецификации, какие параметры критичны
  (HLB, ККМ, вязкость, степень замещения, молекулярная масса, ионность и т. п.);
* **типичные дозировки** с числами и указанием продукта;
* **типичные ошибки** — что ломается и почему (несовместимость, порядок ввода,
  температурный режим, влияние на пену или вязкость);
* **чего ожидать в формуле** — влияние на органолептику, стабильность, ощущения;
* **регуляторные особенности**, если они есть (ограничения, приложения Регламента).

## Формат ответа

Запиши в файл **один JSON-объект**:

```json
{
  "id": "surfactants",                       // id категории из categories.json
  "title": "ПАВ: как устроены поверхностно-активные вещества",
  "lead": "2–3 предложения: о чём статья и чем эта группа важна. 200–400 знаков.",
  "reading_minutes": 7,
  "key_facts": ["...", "..."],                // 4–6 фактов, каждый до 120 знаков
  "sections": [
    {"title": "Что это за группа", "text": "минимум 600 знаков..."},
    {"title": "Как работает", "text": "минимум 600 знаков..."},
    {"title": "Подклассы", "text": "общий обзор 300+ знаков..."},
    {"title": "Как выбирать", "text": "минимум 500 знаков..."},
    {"title": "Дозировки", "text": "минимум 400 знаков..."},
    {"title": "Ошибки в рецептуре", "text": "минимум 500 знаков..."},
    {"title": "Чего ожидать в формуле", "text": "минимум 400 знаков..."}
  ],
  "subtypes": [
    {"name": "Анионные", "text": "минимум 400 знаков: как устроены, примеры, когда выбирать"}
  ],
  "guidelines": [
    {"title": "Что смотреть в спецификации", "items": ["...", "..."]}
  ],
  "example_ids": ["natriy-lauret-sulfat", "kokoamidopropilbetain"],
  "references": [{"title": "...", "url": "https://..."}]
}
```

## Объём и качество

* Суммарный объём текста статьи — **не меньше 5000 знаков** (лучше 7000–9000).
* `subtypes` — **минимум 3 подкласса** (если категория делится на подклассы).
* `guidelines` — минимум 2 блока, в сумме 8+ пунктов.
* `references` — минимум 3 реальные ссылки (учебники, обзоры, CosIng, ECHA, статьи).
* `example_ids` — только те id, которые **реально есть** в каталоге в этой категории.

## Стиль

* Русский язык, технически точно, без маркетинга и без «воды».
* Конкретика вместо общих слов: числа, названия веществ, формулы.
* Не используй: «уникальный», «лучший», «революционный», «в современном мире».
* Можно и нужно использовать списки внутри `text` — разделяй пункты через `\n• `.
* Абзацы разделяй через `\n\n`.

## Проверка перед записью

* JSON разбирается без ошибок;
* все обязательные поля на месте;
* объёмы текстов соответствуют требованиям;
* `example_ids` проверены по `materials.json`;
* ссылки начинаются с `https://`.

## Что вернуть в ответе

Короткий JSON без пояснений:
`{"id":"...","written":true,"chars":число,"subtypes":число,"sections":число,"references":число}`
