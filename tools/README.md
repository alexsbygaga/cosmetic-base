# Служебные скрипты (`tools/`)

Скрипты подготовки и проверки данных каталога. Требуют Python 3.9+ и `openpyxl`
(нужен только `extract.py`). Запускать из корня проекта.

## Порядок работы с данными

```
Косметическая база.xlsx
        │  extract.py
        ▼
data/raw-materials.source.json     ← нормализованный список (129 строк → 129 записей)
        │  recategorize.py
        ▼
категории присвоены по названию сырья
        │  plan.py → make_batches.py
        ▼
data/research-plan.json, data/batches/*.json   ← партии для сбора данных
        │  сбор данных по партиям
        ▼
data/enriched/*.json               ← 33 файла, 128 записей
        │  build_catalog.py
        ▼
data/materials.json + web/data/materials.json
        │  validate_catalog.py
        ▼
отчёт о качестве данных
```

## Скрипты

| Скрипт | Что делает |
|---|---|
| `extract.py` | Читает `Косметическая база.xlsx`, чистит пробелы и переводы строк, объединяет дубликаты, присваивает `id` и `inci_source`. Пишет `data/raw-materials.source.json` и `tools/unique_list.txt`. |
| `recategorize.py` | Присваивает категорию каждой позиции **по названию** (а не по номеру строки). Печатает список исправлений. Это единственный источник истины по категориям. |
| `plan.py` | Собирает партии для сбора данных по смысловым группам (отдушки Syren, экстракты, красители, ПАВ и т. д.). Пишет `data/research-plan.json`. |
| `make_batches.py` | Режет группы на партии по 1–6 позиций и пишет `data/batches/*.json` + `data/batch-manifest.json`. |
| `retry_plan.py` | Определяет, какие группы ещё не собраны, и формирует список для повторного прогона. |
| `build_catalog.py` | **Главный скрипт сборки.** Читает `data/enriched/*.json`, сверяет с исходным списком, приводит все записи к единой структуре, объединяет дубликаты из Excel, пишет `data/materials.json` и копию в `web/data/materials.json`, обновляет запущенный сервер через API и печатает отчёт о покрытии полей. |
| `validate_catalog.py` | Проверка структуры: обязательные поля, типы, уникальность `id`, известные категории, форматы CAS, наличие ссылок и заполненность полей. С `--check-links` проверяет все URL по сети. С `--json` сохраняет отчёт. |
| `colors.py` | Добавляет цвета категориям в `data/categories.json` (для интерфейса). |
| `fixture.py` | Создаёт небольшой отладочный набор данных — удобно для проверки интерфейса. |

## Добавление новых компонентов (происхождение «ИИ»)

Отдельный конвейер для позиций, которые находит и заполняет ИИ:

| Скрипт | Что делает |
|---|---|
| `new_components.py` | Хранит подборку новых компонентов (id, название, категория, INCI-ориентир). Проверяет: ровно 100 позиций, уникальные `id`, известные категории, отсутствие точных совпадений INCI с текущей базой. Пишет `data/new-components.json`. |
| `check_overlap.py` | Ищет точные совпадения INCI между подборкой и текущей базой — чтобы не добавить дубль. |
| `make_batches_ai.py` | Режет подборку на партии по 5 позиций в `data/batches-ai/`. |
| `sync_ai_batches.py` | Приводит `data/enriched-ai/` в соответствие с текущим планом: лишние записи уносит в `data/enriched-ai-legacy/`, а для недостающих формирует партии на дообогащение. |
| `validate_ai.py` | Проверяет, что каждая позиция плана обогащена ровно один раз: нет пропусков, дубликатов и лишних записей. |

Порядок работы:

```powershell
python tools/new_components.py      # проверить и записать план
python tools/check_overlap.py       # убедиться, что нет дублей
python tools/make_batches_ai.py     # нарезать партии
# сбор данных по партиям -> data/enriched-ai/*.json
python tools/build_catalog.py       # собрать каталог: human + ai
```

Если план изменился, `sync_ai_batches.py` сохранит уже собранные данные и подготовит
партии только для новых позиций — пересобирать всё заново не нужно.

## Типичные команды

```powershell
# полностью пересобрать каталог из собранных данных
python tools/build_catalog.py

# проверить качество данных
python tools/validate_catalog.py

# проверить структуру и все ссылки
python tools/validate_catalog.py --check-links

# пересобрать список из Excel (перезапишет категории — потом нужен recategorize.py)
python tools/extract.py
python tools/recategorize.py
```

## Отчёты

* `tools/unique_list.txt` — список сырья в порядке исходного файла, удобно сверять глазами.
* `tools/reports/validate_report.json` — последний отчёт проверки (ошибки и предупреждения).
